# Chart Samples — Modal AABA contrafacts in the Woody Shaw style

> Sprint 0.14. Two first-real-charts shipped through the chart
> pipeline. Same form (32-bar modal AABA in D dorian / G dorian),
> different head melody and articulation choices. The differences
> are visible in the produced PDFs and Demo MP3s.

---

## Sample 1: `modal-sketch` (sprint 0.7)

**Head:** starts on D, plain flowing 8th-note line over pedal
harmony. Open tone, no Shaw-style articulations. The head's job is
to set up the form; the actual improvisation is left to the
soloist.

## Sample 2: `modal-sketch-b` (sprint 0.11 — alt-head)

**Head:** starts on F (a 5th higher than modal-sketch's D), so the
contour shapes the phrase differently and exercises the bridge
modulation differently. Engraving showcases the Shaw articulations
per `docs/COLTRANE-SHAW-ENGRAVING.md` §6:

- **Popped highs:** `<articulations><strong-accent/><tenuto/></articulations>` on every high note (A5/C6/E6 in the bridge; A5/C6 in the A' reprise).
- **Standard pops:** `<articulations><accent/></articulations>` on melodic mid-range notes.
- **Direction text:** "Modal — open, fast swing 8ths" at bar 1, "G dorian — half-valve pickup" at bar 9, "Harmon mute, stem out" at bar 17.
- **Half-valve effect:** the bar 9 pickup uses E6/D6 acciaccatura-style 8th-note pairs (e.g. E6-D6 in beat 3-4 of bar 9) to suggest the half-valve pitch-bend Shaw uses on the bridge pickups.

## Side-by-side articulation comparison

Bar numbers refer to the A section (bars 1-8) and bridge (bars 9-16).

| Bar | `modal-sketch` | `modal-sketch-b` |
|-----|----------------|-------------------|
| 1 (head pickup) | D5 quarter, plain | F5 quarter, **accent** (pops into the entry from above) |
| 2 (high point of A1) | F5 quarter, plain | F5 quarter, **strong-accent + tenuto** (popped high) |
| 3 (downbeat of A2) | A5 half, plain | C6 half, **strong-accent + tenuto** (highest point of head) |
| 6 (A2 cadential) | G5 half, plain | G5 half, **accent + tenuto** (cadential weight) |
| 7 (high D of A3) | F5 quarter, plain | E6 quarter, **accent + tenuto** (register jump) |
| 9 (bridge pickup) | C6 quarter, plain | C6 quarter, **strong-accent**, followed by E6/D6 8th-note pair with **accent + tenuto** (half-valve pickup effect) |
| 11 (bridge high) | E6 half, plain | G6 half, **accent + tenuto** (top of the bridge range) |
| 13 (bridge peak) | E6 quarter, plain | G6 quarter, **strong-accent + tenuto** (highest note in the chart) |
| 15 (bridge cadential) | G6 quarter, plain | B6 quarter, **accent + tenuto** (above-the-staff peak) |
| 17 (mute entry) | F5 quarter, plain | F5 quarter, **accent** (mute open) |
| 22 (A' cadential) | G5 half, plain | G5 half, **accent + tenuto** |

The alt-head's articulation density is roughly 3× higher than the
plain sketch. That's the point — both charts share the same form,
but the alt-head demonstrates the engraving conventions from
`docs/COLTRANE-SHAW-ENGRAVING.md` §6.

## How to read these PDFs in MuseScore

Both `*_Full_Score.pdf` files were produced by MuseScore 4 from
the pipeline's MusicXML outputs. They're transposed scores
(Trumpet in Bb, rhythm in C). To open in MuseScore for editing:

1. Drop the source `.musicxml` into MuseScore (not the PDF — the
   PDF is read-only).
2. Trumpet part will open in Bb (transposed). Piano / Bass /
   Drums in C (concert).

## Regenerating these from scratch

Both charts are derived from the same modal AABA form. To regenerate
or extend:

```bash
# Source files live in /tmp (work product, not in repo):
/tmp/modal-sketch.musicxml       # plain head (sprint 0.7)
/tmp/modal-sketch-b.musicxml     # alt-head with Shaw articulations (sprint 0.11)

# Drop into the production inbox, the chart-watcher picks it up:
cp /tmp/modal-sketch-b.musicxml ~/digital-twin/chart-inbox/

# Wait ~13s for the full chart package to land next to the input.
ls chart-inbox/modal-sketch-b_*.{pdf,mp3}
```

The chart-watcher LaunchAgent (`com.kaidjuric.digital-twin.chart-watcher`,
PID 23200) is already running. Drop-and-forget.

## Open

- **Both PDFs are NOT in the repo.** They're auto-generated by the
  chart-watcher and live in `chart-inbox/`, which is `.gitignore`'d.
  To view them, open the file directly in a PDF reader or copy to
  a non-ignored path.
- **Source MusicXML files are NOT in the repo.** They live in
  `/tmp` as work products. The chart compositions are evolving;
  the repo carries the tooling, the chart itself lives where the
  user iterates on it.
- **No chord-symbol / slash notation yet.** Per `docs/COLTRANE-SHAW-
  ENGRAVING.md` §6, real charts would have chord symbols above
  the piano staff; the current MusicXML pipeline doesn't carry
  those. Adding them requires music21 or similar — a future sprint.
