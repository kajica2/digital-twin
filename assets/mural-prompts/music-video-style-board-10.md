engine-note: >
  Ten prompt sets, one frame each — the SAME frame (the dawn apartment,
  the man at the kitchen table with his back to the camera) in ten
  different visual styles. It is a selection board, not a shot list: one
  frame per style, directly comparable, so the treatment can be chosen
  before a whole video is rendered.
  The frame is the opening of every set in the brief, and the style
  language is that set's own. No reference image travels with these —
  the identity is not what is being chosen here, the LOOK is.
  The account's profile is typed into every prompt so the ambient
  personalization cannot flatten ten different looks into one.
