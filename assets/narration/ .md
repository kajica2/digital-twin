# Five versions of the narration

The five-scene hyperspace page (`pages/from-nothing-to-tools.html`) carries
one line of text per scene. Five alternative scripts below, each fitting
the 5-scene timing (≈5–7 words per line, 12 s total at conversational
pace). Pick the tone — the structure is the same.

Pick one and swap it in by replacing the `text:` field per scene in the
`SCENES` array at the top of the inline `<script>`. The visual flow,
density curve, and palette are unchanged.

---

## 1. Maker — first-person, present tense, "you"

> The version currently shipped. Each line is a single moment of the
> arc, addressed to the person building.

| # | Line |
|---|---|
| 1 | the moment before anything. |
| 2 | a first tool emerges. |
| 3 | the ones only you would build. |
| 4 | they start working together. |
| 5 | now they ship. |

*Voice*: quiet, direct, lower-case. Reads like someone keeping notes
on their own work.

---

## 2. Witness — third-person, observer's voice

> The maker is the subject, not the audience. A friend watches from
> across the room.

| # | Line |
|---|---|
| 1 | a desk, a blank screen, a hand. |
| 2 | the first line of code runs. |
| 3 | the next tool is for the one before it. |
| 4 | the tools start to talk to each other. |
| 5 | today they're part of the world. |

*Voice*: present, declarative, slightly literary. The viewer is the
maker *from the outside*.

---

## 3. Audit — counts, types, edges

> Systems prose. Each scene names a number or a relation; nothing is
> figurative. Reads like a diff that grew into a product.

| # | Line |
|---|---|
| 1 | count: 0.  edges: 0.  deps: 0. |
| 2 | count: 1.  runtime: local.  deps: 0. |
| 3 | count: ~10.  each one runs alone. |
| 4 | count: ~50.  each one calls the others. |
| 5 | count: public.  each one ships. |

*Voice*: monospace, paper-trail. Suits an engineer who'd rather see
the receipt than the cheer.

---

## 4. Honest — anti-marketing, no hype, almost contrarian

> The piece refuses to be inspirational. The arc is the same; the
> language points out the parts the marketing usually hides.

| # | Line |
|---|---|
| 1 | nothing. |
| 2 | you made one thing today. it broke. |
| 3 | the next thing was for the thing that broke. |
| 4 | the third thing reached for the second. |
| 5 | you didn't ask for this. you have it. |

*Voice*: terse, slightly weary, refusing to congratulate the maker.
Worth it if the rest of the surrounding copy is confident — it
brings the room down to ground level.

---

## 5. Manifesto — declarative, maximum compression

> A credo. Five lines, ten words each, no scene does more than name
> one act. Reads like the inside cover of a zine.

| # | Line |
|---|---|
| 1 | nothing. |
| 2 | you took it into your own hands. |
| 3 | you built what only you would build. |
| 4 | your tools know each other. |
| 5 | you ship. |

*Voice*: imperative. Designed to outlive the page — every line is
independently quotable on a poster, in a footnote, in a commit
message subject.

---

## How to swap a version in

Edit `pages/from-nothing-to-tools.html`, find the `SCENES` array near
the top of the inline `<script>`, and replace each `text:` value with
the corresponding row from the chosen version. Five lines, five
edits, no other changes needed — the visual engine keys off the
text element only via `textContent`.
