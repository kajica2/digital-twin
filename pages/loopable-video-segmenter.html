Local tool · sprint 0.21

MP4 → loopable clips.

Split a long video into N segments whose boundaries land on musical beats — each clip plays forward then mirrors back, so dropped into a loop slot it cycles without a visible seam. Beat detection via librosa; rendering via MoviePy. Falls back to equal-time slices when the video has no usable audio. Everything runs locally.

gradio 5 + MoviePy + librosa CLI + UI local-first · no uploads MIT
01

What it does

  • Beat-aligned cuts. Audio is extracted (22.05 kHz mono), beats are detected with librosa.beat.beat_track, and the beat list is split into N contiguous groups — so every segment starts and ends on a musical downbeat.
  • Seamless loops. Each segment is built as [forward, reverse] (vfx.time_mirror) — the tail mirrors back to the head, no visible seam.
  • Always produces output. No audio or too few beats? Equal-duration fallback kicks in instead of failing.
  • ZIP download. segment_01.mp4 … segment_NN.mp4 in one archive.
02

How to run it

Setup is a one-time uv sync (same pattern as the CLIP Interrogator). ffmpeg must be on PATH — MoviePy shells out to it for encode/decode.

Setup (once)

brew install ffmpeg        # if not already installed
npm run lvs:setup           # uv sync --project lib/loopable-video-segmenter
npm run lvs:check           # imports + deps + ffmpeg presence, no model downloads

UI

npm run lvs:ui
# gradio app on http://127.0.0.1:7861  (7860 is the CLIP Interrogator's port)

CLI

npm run lvs:segment -- video.mp4 --segments 4
npm run lvs:segment -- video.mp4 --segments 8 --no-loopable --json
npm run lvs:segment -- video.mp4 --segments 2 --out /path/to/out.zip

--json emits the zip path, segment count and which segmentation path ran (beat detection or equal-time fallback). Exit codes: 0 ok, 2 bad input, 3 runtime failure.

04

How it works

  1. Extract audio to a temp WAV (22.05 kHz mono) via MoviePy.
  2. Detect beats with librosa.beat.beat_track; keep only beat times inside the video duration.
  3. Divide the beat list into N contiguous groups → N (start, end) windows that begin/end on downbeats.
  4. Build each clip: subclip(start, end) then concatenate([sub, sub.fx(vfx.time_mirror)]), encoded h264 + aac.
  5. Zip the segments and hand the archive back (UI file widget or CLI --out).
Quality depends on the audio. Live or percussive music gives the cleanest splits. Spoken word and ambient tracks fall through to the equal-time fallback — the pipeline never refuses to produce output.
05

Notes

The mirrored half plays audio backwards. The time_mirror trick makes visuals loop seamlessly, but the second half of each clip's audio is reversed. Fine for visual loops; for music-video work, mute the second half in your DAW or cross-fade.
  • Source code: lib/loopable-video-segmenter/ (uv-managed, src/loopable_video_segmenter/).
  • MoviePy is pinned to 1.x — the code uses the 1.x API (moviepy.editor, subclip, vfx.time_mirror).
  • Docs: docs/LOOPABLE-VIDEO-SEGMENTER.md. Source repo: github.com/kajica2/loopable-video-segmenter.
