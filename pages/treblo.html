Music generation · Treblo Melodia v3

Five songs from five prompts.

Treblo turns a written prompt into a finished instrumental. The twin's client submits the prompt, waits for Treblo's own answer, and downloads the audio before the link expires — so what lands on disk is a file, not a URL that dies in a week.

100 credits a generation · v3 songs run 2:00–4:45 · mp3 by default · the key never touches the repo

What it is

Treblo is a hosted music model with a public API. You send a prompt — a description of the piece you want — and it returns a task id; the task becomes a song. The model infers the style tags and the tuning from your words, so the recommended call is prompt only: hand-writing tags tends to make the result worse, not better.

For an instrumental, the API takes one extra switch — instrumental: true — and no lyrics at all. Sending lyrics with it is contradictory, so the client drops them rather than sending both.

One v3 generation costs 100 credits. Five prompts cost 500. A failed generation is not charged: Treblo says so, and the client's own run record keeps the task id either way so the attempt is auditable.

Put the key where the repo can't see it

The key lives outside the project — in the environment, or in a file in your home directory. The client reads either, and never writes the key into the tree.

export TREBLO_API_KEY='your-key-here'
printf '%s' 'your-key-here' > ~/.treblo-api-key && chmod 600 ~/.treblo-api-key

A key in the environment wins over the file. The file is the one to use when the twin runs as a service, because a launchd agent inherits a thin environment.

Run it

A pack is one top-level bullet per prompt — the same convention the Midjourney packs use, so one file can feed both pipelines. The client reads the bullets, submits each one, polls Treblo's status endpoint, downloads the audio and writes a catalogue.

npm run treblo:generate -- --prompt-file assets/treblo-prompts/kai-djuric-5.md \
  --out data/treblo/kai-djuric-5 --instrumental

Nothing is spent until you ask for it: --dry-run prints the plan and the credit cost and stops.

npm run treblo:generate -- --prompt-file assets/treblo-prompts/kai-djuric-5.md --dry-run

Where the songs land

Each generation writes an audio file and one catalogue entry. The catalogue holds the prompt, the task id, the file and the size — the trail from a sentence to a file.

prompt → POST /generations/v3 → task_id → poll /generations/status → song_paths → download → data/treblo/<pack>/NN-slug.mp3 + catalog.json

From there a song is a normal file in the twin: the reel pipeline can cut a vertical clip from it, the social worker can package it, and the song indexer can catalogue its metadata.

What to know

The song URLs expire. Treblo's own documentation says so: the links are unlisted, not access-controlled, and they do not last. A run that records a URL and never downloads the audio has produced nothing — so the client always downloads, and a generation without audio is an error rather than a quiet success.

Out of credits is a 402. When the account runs out, the API answers 402 Out of credits and nothing is charged. The client's error names the page that fixes it — treblo.com/developers/account, where a free trial can be activated (verify a card, 3,000 free credits, no charge).

Prompt only is the documented best practice. Tags and lyrics left to the model produce better songs; hand-written tags usually produce worse ones. The client sends the prompt and, for an instrumental, the one flag.
