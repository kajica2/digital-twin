Temple of Control

Three temperature sliders turn a meditation into a visual. Heat is the colour temperature, breath the motion temperature, glow the light temperature. Drop in a .mid and the score becomes the meditation — note-ons ripple out, velocity drives their weight, pitch class shifts their hue. One script tag, one custom element, anywhere.

Feed it a score

Choose a Standard MIDI File and the visual is driven by the note events themselves — beat and onset come out exact, because a note-on is an onset. The tempo map sets the breath rate.

Automap — hardware or keyboard as the desk

A MIDI controller can drive the three temperatures directly. 8-knob controllers are profiled: its eight encoders auto-map to the current mode's three targets, and the mode button cycles the automap modes — temperature, score, tint. Unknown devices fall back to the generic profile.

Keyboard fallback (no controller needed):

  • 1–9, 0 → heat (0.1 → 1.0)
  • Shift+1–9, Shift+0 → breath (0.1 → 1.0)
  • Ctrl+1–9, Ctrl+0 → glow (0.1 → 1.0)
  • M → cycle mode

Plug it into any page

Two files, no build step. The element is a Web Component, so it works on any page in this repo or outside it.

<script src="/lib/meditate-temperature.js"></script>

<meditate-temperature heat="0.38" breath="0.5" glow="0.58"></meditate-temperature>

<script>
  const v = document.querySelector('meditate-temperature');
  v.loadMidi('/audios/score.mid').then(console.log);   // optional: MIDI-driven
  v.setTemp({ heat: 0.8 });                            // three temperatures, 0..1
</script>

Knob support on top of it:

<script src="/lib/midi-automap.js"></script>

MIDI_AUTOMAP.create({
  onMap:  m => v.setTemp(m),          // { heat } | { breath } | { glow }
  onMode: mode => console.log(mode)  // temperature | score | tint
}).request();
