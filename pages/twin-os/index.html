panel 02 · songs

A catalog you can actually search.

The indexer walks your audio directories, reads ID3 + WAV metadata, and writes a searchable catalog at /data/songs/catalog.json. Rebuild it with npm run index-songs.

Tools

Pair the catalog with transcription + export services. Each opens in a new tab; nothing leaves this machine until you upload.

♪ MuScriptor kyutai

Upload audio → get MIDI, per-instrument sheet-music PDFs, full score, and MusicXML. Open-source, MIT-licensed; runs locally via uvx muscriptor serve if you'd rather keep it offline.

open muscriptor.kyutai.org →
🕵️ CLIP Interrogator local

Turn any image into a prompt — or rank it against artist, medium, movement, trending and flavor vocabularies. Local gradio app + CLI under lib/clip-interrogator/; run it with npm run clip:ui.

open the CLIP Interrogator →
🎬 Refael MP4 Maker local

MP3 → MP4 with mood-keyword auto-covers, fully offline — single track, custom image, or batch a folder. One HTML file, three render engines (WebCodecs / FFmpeg.wasm / MediaRecorder), deterministic cover from track name.
