tool · family dashboards

One panel per family, not per suite.

Every suite in npm run test:all lands in one of eight floating panels — watchers, Midjourney, Suno, Treblo, social, media, marketplace, platform. Open a family, read its tests, run commands and docs without leaving the page.

loading catalog…

Families

Pick a family to open its floating panel. The panel uses the same chrome as the floating toolset — traffic lights, drag, collapse — with a 2×2 grid of Tests / Run / Docs / Status.

Drop-in

The component is one script tag. Point src at the catalog and family at an id. 

<script src="/lib/tool-dashboard.js"></script>
<tool-dashboard
  src="/data/twin/tool-dashboards.json"
  family="watchers"></tool-dashboard>
