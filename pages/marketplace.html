Studio Extras

Cover Studies

Twelve square covers in three families — the 1:1 arm of the same world. Each family is one prompt run through five seeds (two for the type family), so the variation you see is lighting and composition drift, not a different scene. Rendered locally on FLUX.2 klein-4B, no credits, no network.

How the type is made. Every word you read on these covers is real type, set in layout over the plate (Arial Black). The plates themselves are rendered with no lettering at all, because a diffusion model paints letter-shaped marks rather than composing glyphs — asked for ‘Chrome Heart’ it produces CHIOME HEART. So the subject is generated and the words are not: a cover that has to read correctly gets its lettering from a font. The type family is the composition study underneath; the lockup is done properly.

System Error

Ten 16:9 plates for the pack card: digital decay, RGB splits, controlled chaos — for experimental, breakcore, glitch and noise artists who break rules on purpose, 100–170 BPM. Rendered locally on FLUX.2 klein-4B (Apple MPS), seeds 9600–9609, 832×464. Unlike the covers above, these are deliberately text-free: no lettering anywhere, on purpose.
