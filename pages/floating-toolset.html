tool 09 · floating toolset

One panel, floating over everything.

Today, now playing, code and patterns — four surfaces the twin keeps an eye on, packed into a draggable corner panel. Drop it on any page with one script tag. No build step, no framework.

What it is

The toolset is a single Web Component, <floating-toolset>, that renders itself in the corner of the viewport and floats above the page. Drag it anywhere. Collapse it to its chrome bar. Close it and a small twin tab stays so you can bring it back.

It reads a JSON payload — the twin's demo state lives at data/twin/toolset.json — and merges it over sensible defaults, so a partial payload never blanks a panel. The position is remembered per browser, in localStorage.

The panel is calm by default. The only motion is the equalizer in Now Playing, and it stops under prefers-reduced-motion. Nothing pops up and nothing pushes a notification at you.

Drop it on a page

Two lines. The component ships its own styles in a shadow root, so it cannot collide with the host page's CSS — but CSS custom properties inherit through the shadow boundary, so the skin still reaches it.

<script src="/lib/floating-toolset.js"></script>
<floating-toolset src="/data/twin/toolset.json"></floating-toolset>
panel: closed

The payload

One JSON object, four panels and a footer. Every key is optional — anything you leave out falls back to the built-in demo state.

KeyShapeWhat it does
titlestringCentre of the chrome bar.
livebooleanShows the red live badge in the corner.
panels.today.items[]{ time, label }One agenda line each.
panels.nowPlaying{ title, meta, peaks[] }The track and its equalizer; peaks are 0..1 heights.
panels.code.items[]{ repo, task, done }One open piece of work each; done fills the tick.
panels.patterns.items[]{ when, label, detail }One observed rhythm each, with the ▸ arrow.
footer{ left, right }The bar under the panels.

The API

Set the payload from JavaScript instead of a file — useful when the twin already has the state in memory.

const panel = document.querySelector('floating-toolset');

panel.setData({
  panels: {
    nowPlaying: { title: 'Shaw — Fair Weather', meta: 'C minor · 92 BPM' },
    code: { items: [{ repo: 'kai-systems', task: 'ship the twin', done: false }] }
  }
});

panel.open();
panel.toggleCollapse();
panel.toggleZoom();

panel.addEventListener('toolset:move', (e) => console.log(e.detail.x, e.detail.y));
