The four Midjourney flows

The first four packages are the MJ pack work processes: write a pack from a lyric, cut it in song order, walk the character through CLIP space, or mutate an edit job's flags without shadowing the prompt's own --style.

Lyrics → frames
lyrics-to-frames
Idea → prompt pack → chosen cells → video cut.
Next in order
next-in-order
Director lyric-order cut — version 1, best match per line.
Evolution
evolution
Three versions; v3 is a nearest-neighbour walk through CLIP space.
Mutation
mutation
Re-evolve an edit job; the prompt owns --style / --s.

Browse + dry-run

Pick a package, read its nodes, dry-run the plan through POST /api/process/<id>. Apply stays on the CLI (and behind the admin key for browserOk packages).

CLI

node lib/process-graph.js --list
node lib/process-graph.js --show lyrics-to-frames
node lib/process-graph.js --dry-run evolution --with-optional
node lib/process-graph.js --apply index-songs
